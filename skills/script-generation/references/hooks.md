# Hooks

First 1–3 seconds. Write five, pick one. A hook earns the next three seconds by opening a loop.

## Mechanics

- **Curiosity gap** — question not yet answered
- **Pattern interrupt** — mid-action, mid-sentence, unpolished — not "an ad"
- **Self-recognition** — viewer's situation named precisely

Specificity wins. *"Someone asked if this survives the shower"* works. *"Are you tired of jewellery that tarnishes?"* fails (pitch voice).

## Patterns

| Pattern | Shape | Notes |
|---|---|---|
| Borrowed question | "Someone asked me if…" / "I keep getting this comment…" | Strongest for sceptical products; pairs with comment graphic in edit |
| Duration flex | "Four months. Never taken it off." | Concrete; implies the objection |
| Failure confession | "I have thrown out four of these." | Needs anti-confusion rule |
| Mid-action open | Visual already moving; VO starts beat two | When the first frame is arresting |
| Objection-first | "I did not believe the waterproof thing either." | Names disbelief first |
| Specific-scenario | "I wore this in the ocean in Mexico…" | One verifiable scene |
| Contrarian | "Stop buying gold-plated anything." | High stop power; payoff must land fast |

## Anti-patterns

| Avoid | Why |
|---|---|
| "Are you tired of…" | instantly an ad |
| "Introducing the…" | brand-first |
| "I'm obsessed with…" | empty enthusiasm |
| "This changed my life" | unfalsifiable |
| "POV: you…" | worn template |
| Question answerable with "no" | permission to scroll |

## Testing

Five hooks from **different** mechanics, not five rewordings. Each must: survive flat read with no music; fit only this product; open a loop the script actually closes. Broken promise kills retention at the pivot, not the hook — fix the pairing.
