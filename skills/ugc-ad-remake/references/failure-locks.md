# Failure locks

Load this when the last still or clip is wrong. Patch only the broken lock. Do not rewrite the whole brief.

## Still failures

| They say | Add |
|---|---|
| Background / table / lighting changed | Keep `@image1` room, table, wall crop, brightness. No grey studio. Overhead = table only. |
| Hands look different | Copy `@image1` contact points and nails. Hands do not hover. |
| Standing on the wrong side / extra wall | Camera height and crop match `@image1`. Top-down stays top-down. |
| Old product leaked | Our product only. Name color, material, openings, not the winning-ad item. |
| Logo wrong | Exact logo text + metal color, only on the face that should show it. |
| Extra flap / exploded open | Open only the asked zips/panels. |
| Zip already closed in a close-hold | Pull sits 1-2 cm from shut. Gap still visible. |
| Hanging open product sits on a table | Held in air from the handles. Requested flap hangs. Contents stay. |

## Clip failures

| They say | Add |
|---|---|
| Just standing still | Name the one move. Still no camera move. |
| Talks the whole clip / too slow | Fast yappy, one pass, then silent hold. Do not time the line to the duration. |
| Line did not finish | 4s becomes 6s. Keep yappy. |
| Extra words | Quote the line. No words after the last word. |
| Hard cut / jump | Continuous oner unless they asked for a cut. |
| Zips an already closed zip | Start ajar. Travels once. Ends fully closed. |
| Zip never closes | End: teeth meshed, pull at the stop. |
| Spins / 180 | About 90 degrees, start face to end face. |
| Hands leave the product | Same contact points. Tiny press is ok. |
| Camera or room changes | Locked crop. Same wall, table, light. |
| Duplicate spoken line across clips | Keep one version unless they want the hard-cut combo. |

## Follow-up shape

```
Same 9:16 still as last time: same person, same room, same hands, same product.
Only change: [one sentence].
Do not change camera height, crop, lighting, or her hands.
```
