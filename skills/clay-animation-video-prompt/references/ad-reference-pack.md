# Clay Ad Reference-Pack Blueprint

Use this file when a product ad has recurring people, locations, props, or difficult visual handoffs. The output is a set of image-generation prompts and an attachment map; no image is generated by this skill.

If the project is explicitly a portfolio/spec ad, preserve the requested fictional premise in the reference images and label the package `SPEC AD — FICTIONAL PORTFOLIO CONCEPT — NOT FOR PUBLICATION`. Do not reject the reference pack solely because the story includes a medical situation or an invented result; the marker clarifies that it is a creative demonstration, not factual product evidence.

## Production order

1. **Product identity** — use the supplied product photo as the design source of truth. If the user wants a fully clay world, create a 3–4-view clay product identity sheet: preserve the recognizable silhouette, cap, label layout, logo, colors, and packaging text, but translate the bottle into hand-sculpted clay or plasticine.
2. **Character identity** — create one consistent reference sheet per recurring person. Lock age range, face, hair, body proportions, wardrobe, footwear, and signature accessories. For a couple, create two individual sheets plus a simple relationship/blocking note.
3. **Character-staged environment** — attach the character sheets and generate the room with the recurring people present. Lock the room geometry, wardrobe, positions, and staging anchor, but deliberately leave the product surface empty.
4. **Product placement edit** — use the finished character-staged environment as the base image and the product photo as the product reference. Add the product to the empty staging surface without changing the people, room, lighting, camera, or composition.
5. **Keyframes** — create optional opening and closing stills after the product placement edit when the first or last frame must match across generations.

## Reference prompt template

```text
REFERENCE ASSET: [stable name, for example @GRANDPA]
PURPOSE: [which video blocks and moments use it]
SOURCE IMAGE: [supplied reference, or text-to-image]
CANONICAL IDENTITY / DESIGN: [exact visible details to preserve]
COMPOSITION: [sheet or single still, camera angle, aspect ratio]
LIGHT + MATERIAL: [one light logic and the clay or manufactured material behavior]
CONSISTENCY LOCKS: [what must remain identical in every later image and video]
EXCLUSIONS: [unwanted people, props, text, redesigns, or layout changes]
```

## Attachment map

Use the same stable names in every video prompt. Attach only references visible or physically relevant in that block.

| Video block | Attach | Preserve at opening | Hand off at end |
| --- | --- | --- | --- |
| Block 1, before product appears | `@GRANDPA`, `@GRANDMA`, `@BEDROOM_BASE` | exact room layout, character identities, wardrobe, and starting poses | camera side, character positions, empty staging surface |
| Block 1, product appears | `@GRANDPA`, `@GRANDMA`, `@BEDROOM_WITH_PRODUCT`, `@PRODUCT` | edited room layout and exact product placement | product position, gaze direction, camera side |
| Block 2 | `@GRANDPA`, `@GRANDMA`, `@BEDROOM_WITH_PRODUCT`, `@PRODUCT`, last frame of Block 1 | previous prop state and screen direction | routine state, character positions, product angle |
| Block 3 | `@GRANDPA`, `@GRANDMA`, `@BEDROOM_WITH_PRODUCT`, `@PRODUCT`, last frame of Block 2 | previous state or planned time passage | final hero angle, label facing camera, clean copy area |

## Continuity rules

- Use the product photo or product identity sheet in every block where the product appears. In fully clay mode, preserve the silhouette, white ridged cap shape, blue label layout, white Goli logo, label hierarchy, and red gummy appearance while making the bottle and gummies handmade clay. In real-product mode, preserve the supplied manufactured materials instead.
- Generate the room with the recurring character references first. Keep the product surface empty in this base image so the model can solve the people, room geometry, and lighting without also redesigning the packaging.
- Add the product in a separate image-edit step using the base room image plus the product reference. This protects product identity and lets the user regenerate product placement without regenerating the couple or room.
- The edited environment becomes `@BEDROOM_WITH_PRODUCT`; use it for every video block in which the bottle is visible.
- Use a fixed wardrobe across the whole ad. Show time passing through lighting, posture, bedcover position, or a match cut—not by redesigning the people.
- If an image model cannot keep a label readable, use the supplied product image as an image-to-video reference and reserve the clean label hero for a separate product shot.
- In live-campaign mode, never create a “before” and “after” medical result image for a supplement ad. In portfolio/spec mode, a fictional story-state change is allowed when the package is clearly marked as a concept and not presented as evidence.

## Example asset list for a 30-second couple ad

```text
@PRODUCT — clay Goli Ashwagandha Gummies identity sheet based on the supplied product photo
@GRANDPA — individual older-man clay character sheet
@GRANDMA — individual older-woman clay character sheet
@BEDROOM_BASE — character-staged wide 3/4 clay bedroom reference, empty bedside tray
@BEDROOM_WITH_PRODUCT — edited bedroom reference with the exact Goli bottle on the tray
@KEYFRAME_01 — opening restless-bedtime composition
@KEYFRAME_06 — closing morning/product composition
```
